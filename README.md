# cgmes_grid_pipeline_exploration
Project Overview
Data engineering exploration of ENTSO-E ReliCapGrid using CIM/CGMES, Python, PostgreSQL, Docker, and automated grid model validation.

# Data Source
ENTSO-E ReliCapGrid — electrical grid test models using CIM/CGMES standards.

# Project Objectives
[1] Explore CIM/CGMES grid model files.
[2] Extract electrical network components and their relationships.
[3] Validate grid model data quality.
[4] Store structured data in PostgreSQL.
[5] Build a reproducible data engineering pipeline.
